# Noted

A simple app for saving and revisiting quotes that are worth remembering.

## About

Noted is a personal quote library for keeping track of meaningful passages from books.

The idea came from a simple problem: when reading, I often come across quotes that I want to remember, but especially when reading in bed, I don't always have a notebook nearby. Noted provides a quick and structured way to save these quotes and revisit them later.

## Features

### Books
- Add books
- View all books
- View a single book
- Edit books
- Delete books

### Quotes
- Save quotes
- View all quotes
- View a single quote
- Edit quotes
- Delete quotes
- Associate quotes with books
- View all quotes from a book
